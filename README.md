# DokuQuest

A voxel sandbox RPG: dig, build, survive and explore, alone or together.

## Download

Get the newest version from the **[Releases](../../releases/latest)** page:

- **Linux:** `DokuQuest-…-x86_64.AppImage`: make it executable and run it.
- **Windows:** `DokuQuest-…-windows-x64.zip`: unzip it anywhere and run `DokuQuest.exe`.
- **Just the game:** `dokuquest.html`: open it in a browser, or install it in the desktop app with Options → Install update…

## Updates

The desktop app checks this page by itself each time the launcher opens. A new game version installs straight away, and when the app itself changes, Options offers **Update the app**. Your worlds are never touched: they live in the app's own folder (`~/.config/Emberwild` on Linux, `%APPDATA%\Emberwild` on Windows).
